## Round behavior

Every round stands alone. Viewers type !join; there are no Predictions, Cup
points, qualification, forced final, account progression or persistent crown.
Each game's own objective score still decides its result. Blade Brawl and Hot
Potato default to chat versus streamer; other games keep their existing rules.
The host can start manually or enable the automatic join countdown.

Visuals come only from [24-toy-theme.md](24-toy-theme.md): filled Toy geometry,
matte balls, local fonts and readable cards. The earlier neon/glossy visual table
is retired. Review current stills against docs/refs/theme-toy.png.
